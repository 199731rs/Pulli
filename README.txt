PULLI STATIC WEBSITE — QUICK START

1. Extract the ZIP folder.
2. Open index.html in Chrome to preview the website.
3. The site is static HTML/CSS/JavaScript; no server or build step is needed.
4. Before publishing:
   - Add the official company email and phone/address if you want them displayed.
   - In index.html, change the contact form mailto:? to mailto:YOUR-COMPANY-EMAIL.
   - Verify product names, descriptions, specifications and availability with the company.
   - Add the correct official social links if needed.
5. To publish free, you can upload the folder to GitHub Pages or Netlify.

The collection images are rendered from the uploaded Pulli Bath Catalogue PDF. Product details are intentionally descriptive and do not invent prices.
